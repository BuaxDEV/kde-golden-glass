# Código de conducta

GoldenGlass adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)
como código de conducta para issues, PRs, discusiones y cualquier otro espacio
del proyecto.

En resumen: trato respetuoso e inclusivo, crítica constructiva sobre el trabajo
y no sobre las personas, y cero tolerancia al acoso.

## Aplicación

El mantenedor ([@BuaxDEV](https://github.com/BuaxDEV)) aplica este código y
puede editar o borrar comentarios, commits o issues, y bloquear temporal o
permanentemente a quien lo incumpla. Para reportar un incidente en privado usa
el reporte de contenido de GitHub (*Report content*) o el [reporte privado de
seguridad](https://github.com/BuaxDEV/kde-golden-glass/security/advisories/new)
indicando que se trata del código de conducta. Los reportes se tratan con
confidencialidad.
